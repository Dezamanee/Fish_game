# Тихая заводь — 2D рыбалка

Мини-игра про рыбалку на закатном пруду. Работает и в браузере, и как отдельное приложение на Electron — из одного и того же `index.html`, без сборщиков и библиотек для самой игры.

## Как играть

1. Зажмите мышь (или пробел) и отпустите — чем дольше держите, тем дальше заброс и крупнее рыба.
2. Дождитесь поклёвки и нажмите в момент, когда поплавок ныряет.
3. На вываживании держите кнопку, чтобы подтягивать рыбу, и отпускайте, когда появится «РЫБА ТЯНЕТ» — иначе леска лопнет.

## Что внутри

- 9 видов рыбы с редкостью, весом и ценой — от плотвы до золотой рыбки.
- Дальний заброс повышает шанс на редкие и крупные экземпляры.
- Вываживание с натяжением лески и рывками рыбы.
- Магазин снастей: удилище, леска, прикормка — по 3–4 уровня улучшений.
- Векторные SVG-иллюстрации: своя рыбка для каждого вида.
- Карточка улова с видом, весом и ценой прямо поверх сцены.
- «Книга рыбака»: коллекция всех видов с личным рекордом по весу.
- Деньги, счётчик улова, рекорд и коллекция сохраняются в localStorage.
- Звук на Web Audio, управление мышью и клавиатурой, поддержка тач-экранов.

## Запуск в браузере

Просто откройте `index.html` двойным щелчком.

Или через локальный сервер:

```
python -m http.server 8765
```

и зайдите на http://localhost:8765

## Десктопная версия

В репозитории лежит и Electron-обвязка, поэтому игра запускается как обычное приложение — в своём окне, без браузера.

```
npm install
npm start
```

Сборка exe:

```
npm run package
```

Готовое приложение появится в `dist/FishGame-win32-x64/FishGame.exe`. Окно 16:9, F11 — полный экран, прогресс сохраняется в профиле приложения.

## Структура проекта

```
index.html        игра: Canvas + инлайн SVG-спрайт, без зависимостей
main.js           окно Electron (1280×760, 16:9, F11)
package.json      скрипты start и package
icon.ico / .png   иконка приложения
README.md         описание
```

`node_modules/` и `dist/` в репозиторий не попадают — они создаются командами выше.

## Технологии

Чистый HTML5 Canvas + JavaScript и встроенный SVG-спрайт; Electron используется только как оболочка для десктопной версии.
