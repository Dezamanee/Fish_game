# Тихая заводь — 2D рыбалка

Мини-игра про рыбалку на тихом озере. Работает и в браузере, и как отдельное приложение на Electron — из одного и того же `index.html`, без сборщиков и библиотек для самой игры.

## Как играть

1. Зажмите мышь (или пробел) и отпустите — чем дольше держите, тем дальше заброс и крупнее рыба.
2. Дождитесь поклёвки и жмите в момент, когда поплавок ныряет.
3. На вываживании ведите рыбку в зелёный сачок: пока она внутри — силы тают, снаружи — растёт натяжение. Если не успеть — рыба уйдёт, снасть смотается обратно, а силы рыбака просядут.

## Что внутри

- **18 видов рыбы** с редкостью, диапазоном веса и длины, ценой и характером боя. Крупные экземпляры выпадают заметно реже мелких.
- **Три локации**: Берег, Камыши и Лодка посреди озера. Камыши открываются со 2 уровня за 250 ₽, Лодка — с 4 уровня за 900 ₽; у каждой свой набор рыбы.
- **Смена суток** длиной 8 минут: рассвет, день, закат, ночь, луна и звёзды, фонарь и светлячки.
- **Погодные события**: звездопад, солнечное затмение, дождь, гроза с молниями и волнами, туман. Влияют на клёв, небо и звук.
- **Уровни и опыт**: за улов дают опыт, за уровень — очко навыков.
- **Древо навыков** из трёх ветвей: снасть, выносливость, удача — 9 узлов по 3 ранга.
- **Силы (HP)**: тратятся на сходах и обрывах, восстанавливаются сами и быстрее в лавке.
- **Магазин снастей** у старого рыбака: удочки, леска, прикормка, покупка перетаскиванием на кассу.
- **Витрина**: по 10 вариантов мебели, одежды и лодок — всё меняет внешний вид сцены.
- **Бестиарий-книга**: рисунок вида, редкость, описание, где водится, диапазон веса и длины, личный рекорд, цена.
- **Живой фон**: дальний берег с песчаной кромкой, лесом, деревней и часовней, камыш, кувшинки, трава и цветы на песке, отражения в воде, дождь, туман и метеоры.
- **Звук на Web Audio**: всплески, поклёвки, ветер, птицы, сверчки, дождь и гром.
- Прогресс (деньги, уровень, навыки, снасти, покупки, открытые локации, коллекция) сохраняется в localStorage, а в приложении — ещё и в профиле Electron.

## Запуск в браузере

Просто откройте `index.html` двойным щелчком.

Или через локальный сервер:

```
python -m http.server 8765
```

и зайдите на http://localhost:8765

## Десктопная версия

В репозитории лежит Electron-обвязка, поэтому игра запускается как обычное приложение.

```
npm install
npm start
```

Сборка exe:

```
npm run package
```

Готовое приложение появится в `dist/FishGame-win32-x64/FishGame.exe`. Окно 16:9, F11 — полный экран.

## Структура проекта

```
index.html        игра: Canvas + инлайн SVG-спрайт, без зависимостей
main.js           окно Electron (1280×760, 16:9, F11, иконка по платформе)
package.json      скрипты start и package
icon.ico / .png   иконка приложения
README.md         описание
```

`node_modules/` и `dist/` в репозиторий не попадают — они создаются командами выше.

## Технологии

Чистый HTML5 Canvas + JavaScript и встроенный SVG-спрайт; Electron используется только как оболочка для десктопной версии.
