# Тихая заводь — 2D рыбалка

Браузерная мини-игра про рыбалку на закатном пруду. Один HTML-файл, без зависимостей и сборки: открывается двойным щелчком или по ссылке GitHub Pages.

## Как играть

1. Зажмите мышь (или пробел) и отпустите — чем дольше держите, тем дальше заброс и крупнее рыба.
2. Дождитесь поклёвки и нажмите в момент, когда поплавок ныряет.
3. На вываживании держите кнопку, чтобы подтягивать рыбу, и отпускайте, когда появится «РЫБА ТЯНЕТ» — иначе леска лопнет.

## Что внутри

- 9 видов рыбы с редкостью, весом и ценой — от плотвы до золотой рыбки.
- Дальний заброс повышает шанс на редкие и крупные экземпляры.
- Вываживание с натяжением лески и рывками рыбы.
- Магазин снастей: удилище, леска, прикормка — по 3–4 уровня улучшений.
- Векторные SVG-иллюстрации: своя рыбка для каждого вида.
- Карточка улова с видом, весом и ценой прямо поверх сцены.
- «Книга рыбака»: коллекция всех видов с личным рекордом по весу.
- Деньги, счётчик улова, рекорд и коллекция сохраняются в localStorage.
- Звук на Web Audio, управление мышью и клавиатурой, поддержка тач-экранов.

## Запуск

Просто откройте `index.html` в браузере.

Или через локальный сервер:

```
python -m http.server 8765
```

и зайдите на http://localhost:8765

Есть и десктопная версия на Electron (папка `C:\fish_game`): отдельное окно, ярлык, без браузера.

## Технологии

Чистый HTML5 Canvas + JavaScript и встроенный SVG-спрайт, без библиотек.
